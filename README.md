# Sprint_6
Проект содержит автотесты части программы, необходимой для наблюдения за животными семейства кошачьих.

## Требования к проекту
1. Maven-проект должен содержать: Jacoco, Mockito и JUnit.
2. Класс Lion не должен зависеть от класса Feline.
3. Должны быть написаны тесты на классы Feline, Cat и Lion, со 100% покрытием.
4. В тесте необходимо реализовать параметризованные тесты.

## Технологии, использующиеся в проекте
1. Java 11
2. Maven 3.9.9
3. JUnit 4.13.2
4. Mockito 3.12.4
5. Jacoco 0.8.7

## Запуск тестов
Чтобы запустить тесты, выполните следующую команду в терминале:
```bash
mvn clean compile
mvn test
